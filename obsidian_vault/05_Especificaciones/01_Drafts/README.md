# 01_Drafts (Borradores / Requerimientos Crudos)

Este directorio está destinado a capturar **ideas sueltas, requerimientos crudos o solicitudes directas desde la fábrica/planta**. 

## Propósito
Servir como bandeja de entrada (Inbox) para cualquier nueva funcionalidad, reporte, optimización o reporte de error que no ha sido estructurado técnicamente ni detallado en historias de usuario.

## ¿Qué colocar aquí?
- Transcripciones de solicitudes verbales de los operadores de planta.
- Capturas de pantalla o reportes informales de errores.
- Ideas iniciales de automatización.
- Checklists rápidas de mejoras deseadas para el sistema de control de peso o pesajes.

## Próximo Paso en el Pipeline
Una vez que el requerimiento crudo es analizado, debe estructurarse en una o más historias de usuario con criterios de aceptación claros en [[02_User_Stories/README|02_User_Stories]].
