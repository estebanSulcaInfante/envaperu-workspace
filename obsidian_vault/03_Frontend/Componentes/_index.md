# Frontend — Componentes Reutilizables

Este directorio documenta patrones y componentes de UI reutilizables. Las fichas de vista indican dónde se aplican; las Tech Specs conservan la autoridad sobre contratos y permisos.

## Patrones Activos

- [[Patron_Capacidades_API_y_Mocks]]: distingue lectura mock, API pendiente, falta de permiso y comando inválido por estado.
- [[Patron_Tablas_Filtros_y_Omnibusqueda]]: estandariza omnibúsqueda, filtros, conteo, vacíos y paginación.

- [[Patron_Altas_En_Contexto]]: permite crear catálogos compactos desde la última opción de un selector sin perder el formulario padre.

## Categorías por Completar

- Formularios de entrada (inputs numéricos, selects de color/material)
- Tablas internas especializadas (detalle horario, control de peso)
- Cards de resumen (totalizadores, métricas)
- Modals (confirmación, edición inline)
- selectores de lotes y ubicaciones;
- visualización de genealogía y eventos de trazabilidad.
